# 차 기록 홈페이지 v2

스크린샷의 피드백을 반영한 iPhone/PC 반응형 차 기록 홈페이지입니다.

반영한 변경점:
- 왼쪽 상단 햄버거 버튼으로 메뉴 열기
- 메뉴에서 차 기록하기 / 최근 기록 / 차 통계 / 설정 전환
- 최근 기록과 차 통계를 하단 고정 영역이 아니라 메뉴에서 열도록 변경
- 제목용 Noto Serif KR + 본문용 Noto Sans KR 폰트 반영
- 기본 정보에 압축차 추가
- 가격과 별도로 총 금액 입력 추가
- 맛/향/전체 평점의 '0.5 단위' 안내 문구 제거
- 기존 0.5점 단위 클릭 평점은 그대로 유지
- 스크린샷처럼 아이보리 + 연두색의 단정한 카드형 UI
- iPhone에서도 터치하기 쉽도록 반응형 적용
- 차 사진 업로드, 기록 저장, 기록 목록, 통계, AI 우리는 법 추천 유지

## Netlify
기존과 동일하게 이 폴더 전체를 GitHub에 올린 뒤 Netlify에서 연결하면 됩니다.

AI 추천은 `netlify/functions/brew.js`를 사용하며, API 키가 없으면 기본 차 종류별 추천으로 동작합니다.


## AI 우리는 법
메뉴의 `AI 우리는 법`에서 차 이름과 차 사진을 입력할 수 있습니다.
Netlify Function이 OpenAI Responses API의 웹 검색 기능을 사용해 차 정보를 검색하고,
사진이 있으면 이미지까지 함께 참고해 우리법을 추천합니다.

필수 환경변수:
- `OPENAI_API_KEY`
- 선택: `OPENAI_MODEL` (기본값 `gpt-5-mini`)

API 키는 브라우저 코드에 넣지 않고 Netlify 환경변수에만 넣어야 합니다.
웹 검색 기능은 API 사용량/요금이 발생할 수 있습니다.
